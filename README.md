# 研究タスク帳

研究プロジェクトのタスクを、優先度・状態・期限・進捗メモつきで管理するiPhone用のWebアプリです。

- データはiPhoneの中（ブラウザのlocalStorage）だけに保存されます。サーバーやログインはありません。
- ホーム画面に追加すると、全画面で開きます。一度開けばオフラインでも動きます。
- このリポジトリにはタスクのデータは入っていません。公開しても中身は見えません。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体 |
| `sw.js` | オフライン対応・高速起動 |
| `manifest.webmanifest` | ホーム画面用の設定 |
| `icons/` | ホーム画面のアイコン |

## 公開（Cloudflare Pages）

1. Cloudflare ダッシュボード → Workers & Pages → 作成 → Pages → Git に接続 → このリポジトリを選ぶ
2. フレームワーク：なし、ビルドコマンド：空欄、出力ディレクトリ：`/`
3. 発行された `https://〜.pages.dev` をiPhoneのSafariで開き、共有ボタン →「ホーム画面に追加」

## 更新するとき

`index.html` などを変えたら、`sw.js` の `VERSION`（例：`'v1'` → `'v2'`）も上げてからpushしてください。iPhoneでは、アプリを一度開いて閉じ、もう一度開くと新しい版になります。

## バックアップ

右上の「⋯」→「ファイルに書き出す」で、全データをJSONファイルとして保存できます。「ファイル」アプリ（iCloud Drive）に保存しておくと、機種変更や故障のときに「読み込む」で戻せます。
